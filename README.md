# feishu-doc-detect

整理 Markdown 文件里的空行，把结果复制到剪切板，直接粘贴就能用。默认不写任何文件，也不改原文件。

需要时还可以顺便调整标题级别，或把结果写到文件。

## 为什么默认只复制到剪切板

把 Typora 文档粘贴到飞书时，两种复制方式都有问题：

- 直接复制 Typora 文档：飞书识别不出来
- 复制源码：会引入多余的空行

所以这个工具整理好空行后，默认只把结果放进剪切板，直接粘贴到飞书就行，不需要改动原文件。

> **提醒**：如果想无损复制，需要在 Typora 中复制源码。

## 安装

```bash
uv tool install .
```

Windows、macOS、Linux 都能用，没有第三方依赖。安装后有 `feishu-doc-detect` 和 `fsdd` 两个命令，二者等价。

## 整理空行

这是工具的主要功能，默认开启：

```bash
fsdd input.md
```

| 原文中连续的空行数 | 处理方式 |
|---|---|
| 1 个 | 删除 |
| 3 个 | 变为 1 个 |
| 其它数量（2 个、4 个及以上） | 列出所有出问题的行号并终止，不复制也不写文件 |

例如：

```text
原文:                结果:
第一行               第一行
(空行)               第二行
第二行               (空行)
(空行)               第三行
(空行)
(空行)
第三行
```

代码块、YAML front matter、HTML 注释内部的空行不检查也不修改。只含空格或 Tab 的行也算空行。

不需要整理空行时，加 `--no-break-lines`。

## 调整标题级别

在文件名后面写一个数字（1～6），最高级标题会变成这个级别，其余标题等距平移。不写数字就不修改标题。

```bash
fsdd input.md 2
```

例如原文有 1、2、3、4 级标题，指定 2 后变为 2、3、4、5 级。平移后超过 6 级的标题会设为 6 级，并给出警告。

代码块（包括其中的 `#` 注释）、YAML front matter、HTML 注释、行内的 `#tag` 和 `C#` 等都不会被当成标题。只支持 `#` 开头的标题，不支持用 `===` / `---` 下划线写的标题。

## 写到文件

默认只复制到剪切板。加 `-o` 后，还会写文件：

```bash
fsdd input.md -o out.md    # 写到 out.md，原文件不动
fsdd input.md -o           # 覆盖 input.md，并生成 input.md.bak
```

只有覆盖原文件时才会备份，已有的 `.bak` 会被覆盖。如果 `out.md` 已经存在，会被直接覆盖，不做备份。

同时指定标题级别时，数字要写在 `-o` 前面：`fsdd input.md 2 -o`。写成 `fsdd input.md -o 2` 时，`2` 会被当成输出文件名。

## 参数

| 参数 | 说明 |
|---|---|
| `input` | 输入的 Markdown 文件，须为 UTF-8 编码 |
| `level` | 目标最高标题级别（1～6），留空则不修改标题 |
| `-o [FILE]`, `--output [FILE]` | 写到文件；`FILE` 留空则覆盖原文件并生成 `.bak` 备份 |
| `--no-break-lines` | 不整理空行 |
| `-h`, `--help` | 显示帮助信息 |

## 剪切板支持

- Windows：直接调用系统接口，无需额外安装
- macOS：pbcopy（系统自带）
- WSL：clip.exe（复制到 Windows 剪切板）
- Linux：需安装 `wl-clipboard`（Wayland）或 `xclip` / `xsel`（X11）

没有写文件时复制失败会报错；加了 `-o` 时复制失败只给出警告，文件照常写入。
